=head1 NAME

HP35s Assembler - translate symbolic assembler programs for the HP-35s

=head1 DESCRIPTION

This project parses HP-35s assembler source, resolves labels and named
constants, and converts the resulting program to calculator keystrokes. It
provides the C<Parser::HPC> parser module and the C<asm2hpc.pl> command-line
frontend. The output is a readable or encoded keystroke listing, not machine
code.

Assembler directives, symbols, and diagnostic messages are also described in
the L<project wiki|https://github.com/brickpool/hp35s/wiki>.

=head1 INSTALLATION

The runtime dependency is L<Parser::MGC> version 0.16 or later. Install the
distribution with the make utility configured for your Perl installation:

  perl Makefile.PL
  make
  make test
  make install

On Windows, use the make utility provided by the Perl distribution, such as
C<dmake>.

=head1 ASSEMBLER FRONTEND

Run the frontend from the project directory. It reads source from standard
input unless an input file is specified; generated output is written to
standard output and diagnostics to standard error.

  perl -Ilib bin/asm2hpc.pl --help
  perl -Ilib bin/asm2hpc.pl --unicode --file=examples/C/C.asm > C.35s

The frontend supports these options:

=over 4

=item * C<-h>, C<--help>

Show usage information.

=item * C<-v>, C<--version>

Show the frontend version.

=item * C<-f FILE>, C<--file=FILE>

Read assembler source from a file instead of standard input.

=item * C<-j>, C<--jumpmark>

Mark jump targets in the listing.

=item * C<-c>, C<--clear>

Include keystrokes to clear calculator program memory.

=item * C<-p>, C<--plain>

Output a 7-bit ASCII listing.

=item * C<-m>, C<--markdown>

Output a Markdown listing with inline HTML.

=item * C<-u>, C<--unicode>

Output a UTF-8 listing.

=item * C<-s>, C<--shortcut>

Include shortcut keystrokes as comments.

=item * C<-e>, C<--encoded>

Output key codes in the macro encoding format.

=item * C<--debug>

Write debug information to standard error.

=back

For example, to create a plain-text listing or an encoded macro stream:

  perl -Ilib bin/asm2hpc.pl --plain --file=examples/C/C.asm > C.raw
  perl -Ilib bin/asm2hpc.pl --clear --encoded --file=examples/J/J.asm \
    | perl extras/tools/uudecode.pl

=head1 PARSER

C<Parser::HPC> parses C<P35S> source and returns a Perl data structure
containing its segments, labels, statements, and optional title and start
address. Its supported grammar, programmatic usage, return structure, and
limitations are documented in L<Parser::HPC>.

=head1 EXAMPLES

The C<examples/> directory contains assembler programs and generated listings.
The C<AppData/> directory contains emulator program files, while
C<AppData/Macros/> contains macro files for importing or testing programs with
the emulator.
